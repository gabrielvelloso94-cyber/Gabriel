# Brand assets

`logo-source.jpeg` is the supplied logo: white artwork on a sage field.

The `logo-*-sage.png` / `logo-*-cream.png` files are generated from it by
`python3 build/extract_logo.py` — transparent PNGs of the exact artwork in each brand
colour, which the catalogue embeds directly. Do not edit them by hand; edit the source
and rerun the script.

Use the sage marks on cream backgrounds and the cream marks on sage backgrounds.
